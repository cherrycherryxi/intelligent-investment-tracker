# 实现计划：智能外汇与债券投资追踪 Agent

## 概述

本实现计划基于 Week 7 的 7 天开发计划，将智能外汇与债券投资追踪 Agent 从设计转化为可执行的代码任务。系统采用 MCP Server 架构，使用 Python 3.9+ 和 FastAPI 框架，集成 OCR 技术、汇率爬虫和 AI 推理模型（Claude API 或 DeepSeek-R1）。

**核心技术栈**：
- 后端：Python 3.9+, FastAPI
- 数据库：PostgreSQL/SQLite
- 缓存：Redis
- OCR：Tesseract/百度 OCR/腾讯 OCR
- AI 推理：Claude API / DeepSeek-R1
- 架构：MCP Server 工具层 + Skills 复用体系

## 技术栈总结

- **数据库迁移**: Alembic
- **缓存**: Redis
- **OCR**: Tesseract / 百度 OCR / 腾讯 OCR
- **AI 推理**: Claude API / DeepSeek-R1
- **定时任务**: APScheduler
- **日志**: Python logging
- **测试**: pytest, pytest-cov
- **代码质量**: pylint, flake8, mypy
- **容器化**: Docker, docker-compose
- **CI/CD**: GitHub Actions
