# OpenWolf Protocol

This project uses OpenWolf-style context management.

Before reading project files, check `.wolf/anatomy.md`.
Before generating code, check `.wolf/cerebrum.md`.
Before fixing bugs, check `.wolf/buglog.json`.

Avoid re-reading files already read in the current session unless they changed.

After meaningful file changes:
- Update `.wolf/anatomy.md` if files were created, deleted, renamed, or their purpose changed.
- Append a short note to `.wolf/memory.md`.

# Verification

When asked "openwolf ping", reply exactly: OPENWOLF_AGENTS_LOADED.
